# Dailyhunt

> Dailyhunt is India's largest local-language content and news aggregation platform, operated by VerSe Innovation (Bengaluru). It aggregates news, video and short-form "DailyShare" cards from 600+ publisher partners across fourteen Indian languages, and syndicates that catalogue to approved partners — OEMs, browsers, apps and PWAs — through a signed HTTP API. Alongside syndication it runs an advertising stack: the Dailyhunt Direct self-serve ad platform, a JavaScript Tracker SDK for down-funnel conversion tracking, and an E-Commerce Shopping Catalog API for vendor product feeds. VerSe Innovation also operates the Josh short-video app.

This file was GENERATED by API Evangelist from the Dailyhunt profile at https://apis.io. Dailyhunt publishes no llms.txt of its own (/llms.txt returns 404 on every Dailyhunt host, probed 2026-08-04).

## Access model — read this first

- Access is **partner-gated, not self-service.** Dailyhunt provisions an API Key, a Secret Key and a Partner Code over email during onboarding. There is no developer signup for the Content Syndication API.
- The production host `feed.dailyhunt.in` **has no public DNS A record** (probed 2026-08-04). The API cannot be reached from the open internet, only from a partner arrangement.
- Every request is **signed**: API key in `Authorization: key=<API Key>`, plus a Base64 HMAC-SHA1 `Signature` header over the URL-encoded, lexicographically sorted query string plus the uppercased HTTP method. A `ts` millisecond timestamp must be in the signed parameter set.
- Every request carries a **`puid`** (the partner's unique id for the end user), and Dailyhunt returns a **`dhFeedV1`** cookie that must be persisted per user and replayed.
- Consumers carry **mandatory write-back obligations**: POST per-card `trackData` to the returned `trackUrl` on every list view, fire the returned ComScore pixel URLs on every list view, and preserve Dailyhunt's tracking parameters when following a card's `deepLinkUrl`.

## APIs

- [Dailyhunt Content Syndication API](https://api-syndication.dailyhunt.in/): Channel discovery (news, location, video, DailyShare/viral), paginated content fetch, keyword search, supported languages, card feedback, live cricket score and commentary, and the mandatory view-tracking callback. Base URL `http://feed.dailyhunt.in/api/v2/syndication`.
- [Dailyhunt E-Commerce Shopping Catalog API](https://developer.dailyhunt.in/ads/docs/shopping-catalog/): Vendor product-catalog creation and asynchronous batch CREATE/UPDATE/DELETE of product rows, with status polling. Base URL `https://money.dailyhunt.in/shopping-catalog/v1`.

## Reference data

- **Languages (14):** en English, hi Hindi, mr Marathi, gu Gujarati, pa Punjabi, bn Bangla, kn Kannada, ta Tamil, te Telugu, ml Malayalam, or Oriya, ur Urdu, bh Bhojpuri, ne Nepali.
- **Content types:** STORY, VIDEO, PHOTO, ASTROLOGY, VHMEME (DailyShare), BANNER, QUESTION_MULTI_CHOICES, HTML.
- **Feature mask (`pfm`) bits:** LIVE_TV_CARD 1, CRICKET_CARD (brief) 8, HERO_CARD 16, VIDEO_CHANNELS 32, VIRAL_CHANNELS 64, CRICKET_CARD (detailed) 128. Bits 2 and 4 reserved. `pfm` is the sum of enabled bits.
- **Errors:** bare HTTP status codes only — 401 invalid API key, 403 invalid signature, 500 internal error; 400/204 on tracking (204 = success); 204 on cricket streams = no match. No problem+json body.
- **Pagination:** follow `nextPageUrl` verbatim (it carries opaque `pageScrollStart`, `psi`, `dsOffset` state); refresh and re-sign only `ts`.
- **Images:** returned as templates `http://bcdn.newshunt.com/{CMD}/{W}x{H}_{Q}/(folder).{EXT}` — fill in crop|resize, width, height, quality, extension per device.
